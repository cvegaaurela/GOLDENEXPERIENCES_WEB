# 🌿 Golden Experiences — Agencia de Turismo en Colombia

Sitio web estático para **Golden Experiences**, una agencia de turismo colombiana especializada en experiencias exclusivas, turismo personalizado y recorridos premium por destinos únicos del país.

---

## 📋 Descripción

Golden Experiences es una agencia de viajes enfocada en ofrecer recorridos auténticos e inolvidables por Colombia. El sitio presenta los paquetes turísticos disponibles, la filosofía de la empresa, sus términos y condiciones, y un canal de contacto directo con el equipo.

---

## 🏖️ Paquetes Turísticos

1. **Vive Colombia, Viaja por Ella** — Recorrido de 15 días por las cinco regiones del país: La Guajira, Eje Cafetero, región paisa, selvas del sur y llanos orientales.

2. **Trilogía Colombiana** — Bogotá, Medellín y Cartagena en un solo itinerario que combina historia, modernidad y Caribe.

3. **Caribe Dorado** — Experiencia en el litoral caribe colombiano: playas cristalinas, pueblos coloridos y vida marina.

4. **Golden Personal** — Paquetes completamente personalizados adaptados a cada viajero: escapadas románticas, viajes familiares, aventura extrema o turismo VIP.

## 🚀 Cómo Ejecutar el Proyecto

Por ser un sitio estático, no requiere instalación ni servidor especial.

1. Clona o descarga el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/golden-experiences.git
   ```

2. Abre el archivo `index.html` directamente en tu navegador, o usa una extensión como **Live Server** en VS Code para una mejor experiencia de desarrollo.
